# 板块二：技术实现与效果验证

## 1. 系统架构设计
- 前端（React + Ant Design）：
  - 页面：热门榜单、商家详情、商家后台、预警中心、预警设置、反馈
  - 即时预警提示、红点与横幅提醒、导航至详情与高德地图
- 后端（FastAPI + SQLite/可切换PG）：
  - API：商家认证/榜单/赞助/点击埋点、预警/设置、反馈、OCR与分析
  - 服务：`merchant_service`、`analytics_service`、`anti_fraud`、`alert_service`、`notify_service`
  - 定时：2小时榜单更新与预警巡检后台任务
- AI/ML：
  - OCR增强、规则+模型融合的风险评估、反作弊（点击/评论/排名操纵）
  - 联邦学习MVP（本地更新+FedAvg聚合），预留差分隐私与灰度发布

数据流（关键路径）
1) 账单创建 → 即时风险评估 → 事件入库 → 通知（尊重偏好与静默）  
2) 点击埋点 → 反作弊检测 → CPC计费与曝光效果回传  
3) 2小时任务 → 榜单滚动与预警漏发补发  

## 2. 算法和模型（原理与选择）
- 规则引擎（可配置）：金额阈值、时间窗口频次、类别异常等 → 可解释、低延迟。
- 模型融合（可拓展）：
  - OCR票据异常信号、消费画像特征（波动、极值、类别多样性）
  - 联邦学习：FedAvg 聚合，客户端梯度裁剪 + DP噪声（可选）
  - 反作弊：同IP/指纹频次、行为序列特征、可疑点击模式识别

阈值建议与默认（可在设置页改）
- 高≥0.8，中0.5~0.8，低<0.5；静默22:00-7:00，高等级可突破静默（可关）。
